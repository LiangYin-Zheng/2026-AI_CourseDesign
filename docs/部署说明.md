# 部署说明

## 1. 环境要求
- 操作系统：macOS / Linux / Windows（建议具备 Python 3.10+）
- 运行依赖：见 `requirements.txt`，当前包括 NumPy、Pandas、scikit-learn、matplotlib、alive-progress
- 推荐入口：使用本项目已有的 Python 解释器或课程环境中的 Python 解释器

## 2. 安装方式
### 2.1 使用当前项目环境
若当前环境已具备 `requirements.txt` 中列出的依赖，可直接执行主入口命令，无需额外安装。

### 2.2 手动准备依赖
如需独立部署，请根据 `requirements.txt` 准备最小依赖环境：

```bash
python -m pip install -r requirements.txt
```

## 3. 启动方式
### 3.1 训练并生成全部产物
```bash
python main.py train
```

### 3.2 启动桌面界面
```bash
python main.py gui-local
```

### 3.3 执行单样本预测
```bash
python main.py predict --json '{"gender":"Male","age":24,"height_m":1.75,"weight_kg":85,"family_history_with_overweight":1,"high_calorie_food_frequency":1,"vegetable_intake_score":2.0,"main_meals_per_day":3.0,"snacking_frequency":"Sometimes","smokes":0,"water_intake_liters":2.0,"calorie_monitoring":0,"physical_activity_score":1.0,"technology_use_hours":1.0,"alcohol_consumption":"Sometimes","transportation_mode":"Automobile"}'
```

## 4. 日志说明
- 日志文件默认写入 `output/logs/project.log`。
- 终端侧重点输出 `INFO` 及以上级别的运行状态。
- 文件侧记录更完整的结构化日志，并自动轮转和保留历史文件。
- 日志实现位于 `src/log/project.py`，基于标准库 `logging` 统一封装。

## 5. 使用步骤
1. 确认 `data/obesity_level.csv` 存在。
2. 运行训练命令，生成模型文件和可视化图表。
3. 启动桌面界面或执行单样本预测命令。
4. 查看预测结果或训练产物摘要。

## 6. 常见问题
### 6.1 找不到模型文件
原因：未先执行训练命令。
处理：先执行 `python main.py train` 生成 `output/models/` 下文件。

### 6.2 预测结果异常
原因：提交字段缺失、字段类型错误，或模型文件损坏。
处理：检查请求 JSON 字段是否与命令行示例一致，必要时重新执行训练流程。
