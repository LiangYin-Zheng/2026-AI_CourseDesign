# 部署说明

## 1. 环境要求
- 操作系统：macOS / Linux / Windows（建议具备 Python 3.10+）
- 运行依赖：NumPy、Pandas、`loguru`（未安装时会回退到标准库 `logging`）
- 推荐入口：使用本项目已有的 Python 解释器或课程环境中的 Python 解释器

## 2. 安装方式
### 2.1 使用当前项目环境
若当前环境已具备 `numpy`、`pandas`，可直接执行主入口命令，无需额外安装。

### 2.2 手动准备依赖
如需独立部署，请根据 `requirements.txt` 准备最小依赖环境。

## 3. 启动方式
### 3.1 训练并生成全部产物
```bash
/Users/liang/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 main.py train
```

### 3.2 启动本地演示服务
```bash
/Users/liang/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 main.py serve-web --host 127.0.0.1 --port 8000
```

默认会自动生成临时自签证书，因此浏览器可能提示“不受信任”。这是本地演示场景下的正常现象。

## 4. 日志说明
- 日志文件默认写入 `output/logs/project.log`。
- 终端侧重点输出 `INFO` 及以上级别的运行状态。
- 文件侧记录更完整的结构化日志，并自动轮转和保留历史文件。

## 5. 使用步骤
1. 确认 `data/obesity_level.csv` 存在。
2. 运行训练命令，生成模型文件和可视化图表。
3. 运行服务命令，看到终端输出 `Web 演示服务已启动：https://127.0.0.1:8000`。
4. 浏览器访问 `https://127.0.0.1:8000`。
5. 在页面输入特征后提交预测，查看结果。

## 6. 常见问题
### 6.1 找不到模型文件
原因：未先执行训练命令。
处理：先执行 `python3 main.py train` 生成 `output/models/` 下文件。

### 6.2 端口无法绑定
原因：当前系统权限或端口占用导致服务无法启动。
处理：更换端口，或在允许本地回环地址监听的前提下重新启动。

### 6.3 页面可以打开但预测失败
原因：提交字段缺失、字段类型错误，或模型文件损坏。
处理：检查请求 JSON 字段是否与 API 文档一致，必要时重新执行训练流程。
