## 使用说明

- 本字典只依据 `data/obesity_level.csv` 的实际表头、dtype、取值和范围建立。
- “中文名称/单位”若仅能从英文名推测或没有数据说明，明确标记“待确认”；不得把推测当作官方定义。
- “允许范围”是本次文件的**观察范围/集合**，不是医学或业务合法边界。
- 原始值必须原样保存；友好名称仅能通过配置映射展示。

5. 在以上信息确认前，界面可规划控件但不得将猜测文案定稿。
