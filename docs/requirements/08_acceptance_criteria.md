# 项目验收标准

## 通用判定规则

- 每条标准必须有文件、命令输出、自动化测试、图表或人工审查记录之一作为证据。
- “代码存在”“界面能打开”“效果较好”不构成通过；运行失败、缺失证据、测试集泄漏或虚构结果均判失败。
- 模型不设置未经课程给出的最低准确率。性能验收以流程正确、指标完整、基线/优化可复现和结果有分析为准。

## 否决项

任一情况直接阻止阶段/最终验收：原始数据被覆盖；系统 Python 被用于正式运行；测试集参与调参/拟合；手写算法由 sklearn 分类器替代；结果或日志被虚构；界面宣称医疗诊断；缺失必需报告/PPT/日志；自动化测试失败未说明。
