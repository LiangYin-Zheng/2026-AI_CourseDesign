## 已确认假设

| ID | 假设 | 依据 | 若失效的动作 |
|---|---|---|---|
| AS-01 | 当前指定仓库和 `origin` 是项目真源 | Git 根目录和 remote 已核验 | 停止写入并向用户报告 |
| AS-02 | 唯一正式 Python 环境是指定 Conda 路径 | 用户明确指定且实测 3.10.20 | 更新长期上下文前先获用户确认 |
| AS-03 | `0be1dad` 是目标候选 | 实际最后一列，7 个肥胖等级样式值 | 由教师/数据说明确认新目标后更新配置与文档 |
| AS-04 | `id` 是非业务顺序标识 | 0–20,757 且逐行等于索引 | 若有业务定义，重新审查但仍防止伪相关 |
| AS-05 | 训练/验证/测试初始比例 70/15/15、种子 42 | 阶段一技术决策，课程未指定具体数值 | 在训练前以配置化变更并更新测试/文档 |
