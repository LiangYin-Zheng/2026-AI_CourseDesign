## 缺失、重复与标识

- 18 个字段缺失数均为 0。
- 使用全部 18 列判定，重复行数为 0。
- 去除 `id` 后再判定，重复记录仍为 0；因此 `id` 没有掩盖内容重复。
- `id` 恰好为从 0 到 20,757 的连续行序号，且每行等于 DataFrame 行索引。它不适合作为人工输入，默认应排除出模型；阶段三以配置和测试固定该规则。

## 初步关系观察（不作因果结论）

- Age 与 Weight 的 Pearson 相关系数约 0.283；Height 与 Weight 约 0.417；Weight 与 `family_history_with_overweight` 的数值编码约 0.514；Weight 与 CH2O 约 0.318。
- Age 与 TUE 约 -0.296，Height 与 FAF 约 0.295。编码变量的相关系数依赖编码含义，只能作为筛查线索。
- 目标分组的 Weight 均值从 `Insufficient_Weight` 的 49.861 到 `Obesity_Type_III` 的 117.697，显示体重与类别有明显关联；但组间范围有重叠，不能由此断言单一字段决定目标。
- 由 `Weight / Height²` 临时派生的观察性 BMI（仅用于审查、未写入数据）在各目标组均值依次呈总体上升趋势，但类别范围仍有明显交叠。因此它既是重要解释候选，也需要审查“目标是否由身高体重/BMI 构造”的标签泄漏风险。

## 潜在异常与数据质量风险

- 连续变量 IQR：Age 合理围栏 `[11, 35]`，有 1,074 条（5.17%）在上界外；这只反映分布偏斜，不表示年龄错误。
- Height IQR 围栏约 `[1.435, 1.959]`，4 条值为 1.975663；均未超出总体观察范围，暂不删除。
- Weight、FCVC、CH2O、FAF、TUE 按 IQR 无围栏外记录。
- NCP 与 0/1 字段的 IQR 会因大量集中值产生误导，不作为异常删除规则。
- Age 等字段出现小数，可能来自插值、合成或连续化处理；数据来源和生成方式待确认。
- 极少类别（如 MTRANS 的 Bike 32、Motorbike 38；SMOKE=1 为 245）可能造成划分和 one-hot 特征稀疏，需分层目标并在训练集检查类别覆盖。

## 潜在数据泄漏字段

1. `id`：严格顺序标识，默认排除。
2. `Weight` 与 `Height`：是课程指定分析和输入字段，但若目标由 BMI 规则生成，会形成标签定义泄漏。需在阶段三报告目标来源不明的限制，并开展含/不含派生 BMI 或关键字段的对照分析；不得因此擅自删除课程要求字段。
3. 目标自身及任何由目标映射生成的中文标签不得进入特征矩阵。
4. 全数据拟合编码/标准化、在划分前做目标驱动清洗或用测试集选参数均属于流程泄漏，测试必须阻止。
