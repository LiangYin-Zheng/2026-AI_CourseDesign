# 项目范围说明

## 必须实现（In Scope）

1. 基于仓库实际 CSV 的数据读取、质量检查、清洗、训练/验证/测试分层划分和无泄漏预处理。
2. Age、Height、Weight 等实际数值字段的单变量、双变量、多变量分析、相关性热力图及文字解释。
3. sklearn `LogisticRegression` 与 `MLPClassifier` 的基线、验证集优化、最终测试和产物保存。
4. NumPy 手写多分类逻辑回归和前馈神经网络，包括核心数学过程、训练曲线、测试和统一接口。
5. 四模型统一比较：完整分类指标、混淆矩阵、分类报告、训练/推理时间、复杂度、优缺点和适用场景。
6. 清新简约的交互系统：首页、数据分析、模型训练、预测、模型比较。
7. 自动化测试、配置、日志、依赖与运行说明。
8. 每日日志、三次周报 PPT、最终模板报告及验收材料。

## 可选增强（Should/Could Have）

- 模型结果历史浏览、指标导出、图表下载。
- 在不泄漏测试集的前提下增加校准曲线、学习曲线或特征解释。
- 可访问性增强、暗色模式、训练取消/恢复。
- 在四个必需模型完成后，增加仅作参考的额外模型；不得取代必需模型。

可选项只有在必需项验收通过、时间允许且不会改变阶段顺序时实施。

## 明确不实现（Out of Scope）

- 医疗诊断、治疗建议、临床决策、真实医院部署或医疗器械认证。
- 采集个人健康数据、账号系统、云端多用户服务、支付和商业化。
- 移动端原生应用、分布式训练、GPU 集群、在线持续学习。
- 在阶段一训练模型、调参、开发算法或编写正式界面代码。
- 修改/覆盖原始 CSV，或用网络同名数据替换仓库数据。
- 为追求复杂度引入深度学习框架；既定神经网络以 sklearn MLP 和 NumPy 前馈网络为边界。

## sklearn 与手写算法边界

| 维度 | sklearn 版本 | 手写版本 |
|---|---|---|
| 核心分类器 | `LogisticRegression`、`MLPClassifier` | NumPy Softmax 回归、前馈神经网络 |
| 允许复用 | 配置、划分、预处理、评估、产物协议 | 同左；可用 NumPy 矩阵运算 |
| 禁止 | 测试集调参、绕过 Pipeline 泄漏 | 用 sklearn 分类器替代核心训练/预测 |
| 顺序 | 先完成并验收 | sklearn 完成后开始 |

## 预测与医学诊断边界

- 对外名称可使用“肥胖风险预测”，但结果页必须显示“仅供课程项目演示，不构成医疗诊断或健康建议”。
- 类别概率是模型置信输出，不等于真实患病概率；不得给药、饮食治疗或临床结论。
- 数据代表性、字段语义、类别来源尚有限，最终报告必须说明局限和误判风险。

## 范围控制规则

1. 变更新增需求时，先更新需求、追踪矩阵、风险和验收标准，再排期。
2. 当前阶段只处理其定义的产物；通过 `08_acceptance_criteria.md` 的阶段门禁后才能进入下一阶段。
3. 必需项优先于可选增强，课程证据优先于技术炫技。
4. 未来工作始终标记“计划/待实现”，只有存在运行或审查证据时才标记完成。
