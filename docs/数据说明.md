# 数据说明

## 1. 数据集概况
- 数据文件：`data/obesity_level.csv`
- 样本量：20758
- 原始字段数：18
- 目标字段：原始字段为 `0be1dad`，清洗后统一为 `obesity_level`

## 2. 字段说明
| 原始字段 | 清洗后字段 | 数据类型 | 字段含义 |
| --- | --- | --- | --- |
| id | record_id | int | 样本编号 |
| Gender | gender | string | 性别 |
| Age | age | float | 年龄 |
| Height | height_m | float | 身高（米） |
| Weight | weight_kg | float | 体重（千克） |
| family_history_with_overweight | family_history_with_overweight | int | 家族肥胖史，0/1 |
| FAVC | high_calorie_food_frequency | int | 是否偏好高热量饮食，0/1 |
| FCVC | vegetable_intake_score | float | 蔬菜摄入评分 |
| NCP | main_meals_per_day | float | 每日正餐次数 |
| CAEC | snacking_frequency | string | 加餐频率 |
| SMOKE | smokes | int | 是否吸烟，0/1 |
| CH2O | water_intake_liters | float | 日饮水量 |
| SCC | calorie_monitoring | int | 是否关注热量摄入，0/1 |
| FAF | physical_activity_score | float | 运动频率评分 |
| TUE | technology_use_hours | float | 电子设备使用评分 |
| CALC | alcohol_consumption | string | 饮酒频率 |
| MTRANS | transportation_mode | string | 出行方式 |
| 0be1dad | obesity_level | string | 肥胖等级标签 |

## 3. 标签说明
清洗后的标签类别共 7 类：
1. `Insufficient_Weight`
2. `Normal_Weight`
3. `Overweight_Level_I`
4. `Overweight_Level_II`
5. `Obesity_Type_I`
6. `Obesity_Type_II`
7. `Obesity_Type_III`

## 4. 数据清洗说明
1. 将原始错误标签 `0rmal_Weight` 统一修正为 `Normal_Weight`。
2. 将原始错误列名 `0be1dad` 统一修正为 `obesity_level`。
3. 将 `CAEC` 和 `CALC` 中的字符 `0` 统一映射为 `Never`，避免类别语义不一致。
4. 对年龄、身高、体重、饮水量、运动评分、电子设备使用评分执行合理区间裁剪，降低异常录入值影响。
5. 新增衍生特征：
   - `bmi`：体重 / 身高²，用于增强肥胖解释能力。
   - `sedentary_transport`：是否久坐型出行。
   - `snacking_score`：加餐频率风险分值。
   - `alcohol_score`：饮酒频率风险分值。
   - `behavior_risk_score`：综合行为风险分值。

## 5. 数据类型处理策略
- 数值变量：标准化后送入模型训练。
- 类别变量：采用独热编码。
- 标签变量：编码为整数类别索引。
