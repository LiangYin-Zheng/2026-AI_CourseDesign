# 测试说明

## 1. 测试内容
1. 数据清洗是否正确修正错误列名和错误标签。
2. 特征预处理是否能正确输出模型输入矩阵。
3. 逻辑回归与神经网络是否能在小样本上完成训练。
4. 完整训练流程是否能输出模型、图表和评估文件。
5. 本地接口服务是否能返回健康状态、训练摘要和预测结果。

## 2. 测试方法
### 2.1 单元测试
执行命令：
```bash
python -m unittest tests/test_project_pipeline.py tests/test_sklearn_pipeline.py tests/test_progress.py -v
```

### 2.2 集成测试
执行命令：
```bash
python main.py train
```

### 2.3 接口测试
健康检查：
```bash
curl -s http://127.0.0.1:8000/health
```

预测请求：
```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/predict \
  -H 'Content-Type: application/json' \
  -d '{"gender":"Male","age":24,"height_m":1.75,"weight_kg":85,"family_history_with_overweight":1,"high_calorie_food_frequency":1,"vegetable_intake_score":2.0,"main_meals_per_day":3.0,"snacking_frequency":"Sometimes","smokes":0,"water_intake_liters":2.0,"calorie_monitoring":0,"physical_activity_score":1.0,"technology_use_hours":1.0,"alcohol_consumption":"Sometimes","transportation_mode":"Automobile"}'
```

## 3. 测试结果
1. 完整训练流程执行成功后，会生成 `output/models/`、`output/figures/`、`output/evaluation/`、`output/reports/` 等目录产物。
2. 已验证 `GET /health` 返回：
```json
{"success": true, "message": "service is running"}
```
3. 已验证 `GET /api/v1/dashboard` 可返回训练摘要。
4. 已验证 `POST /api/v1/predict` 返回有效预测结果。

## 4. 已知问题
1. 若自定义环境未安装 `requirements.txt` 中列出的依赖，需要先补齐依赖再执行训练或服务命令。
2. 模型为纯 NumPy 手写实现，训练速度和效果上限不及成熟深度学习框架。
3. 本地服务启动时若系统限制端口绑定，需要放开本机回环地址权限后再启动。

## 5. 改进建议
1. 可进一步增加特征组合和更细粒度调参策略，以提升多分类效果。
2. 如果需要更丰富的演示页面，可继续增强 `src/interfaces/web/templates.py` 中的前端交互。
